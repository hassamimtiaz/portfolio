# Hassam Imtiaz — Portfolio

Personal portfolio for **Hassam Imtiaz**, Principal Software Engineer.

## Stack

- React 19 + Vite
- Custom CSS (no UI kit)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content

Update copy, experience, and projects in `src/data/content.js`.
Replace assets in `public/images/` and `public/files/`.
