# Images Folder

This folder contains all the images used in your portfolio website.

## Required Images

### Profile Image
- **File:** `profile.jpg`
- **Size:** 500x500px (minimum)
- **Format:** JPG or PNG
- **Usage:** Profile picture in the About section
- **Description:** Professional headshot or profile photo

### Project Images
- **File:** `project-ecommerce.jpg`
- **Size:** 800x400px (minimum)
- **Format:** JPG or PNG
- **Usage:** E-Commerce Platform project thumbnail

- **File:** `project-taskmanager.jpg`
- **Size:** 800x400px (minimum)
- **Format:** JPG or PNG
- **Usage:** Task Management App project thumbnail

- **File:** `project-weather.jpg`
- **Size:** 800x400px (minimum)
- **Format:** JPG or PNG
- **Usage:** Weather Dashboard project thumbnail

- **File:** `project-portfolio.jpg`
- **Size:** 800x400px (minimum)
- **Format:** JPG or PNG
- **Usage:** Portfolio Website project thumbnail

## Image Guidelines

1. **Profile Image:**
   - Use a professional headshot
   - Square aspect ratio (1:1)
   - High resolution (at least 500x500px)
   - Good lighting and clear background

2. **Project Images:**
   - Screenshots of your projects
   - Landscape aspect ratio (2:1 recommended)
   - High resolution (at least 800x400px)
   - Show the main features of each project

## Fallback System

If an image is not found or fails to load, the website will automatically show:
- Emoji placeholder for profile image (👨‍💻)
- Project icon placeholder for project images (💻)

## Adding New Images

1. Place your image files in this folder
2. Use the exact filenames listed above
3. Ensure images are optimized for web (compressed but still high quality)
4. Test that images load correctly in your browser

## Image Optimization Tips

- Use JPG for photographs
- Use PNG for screenshots with text
- Compress images to reduce file size
- Keep file sizes under 500KB for optimal loading
